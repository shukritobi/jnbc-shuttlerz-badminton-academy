# JNBC Shuttlerz Badminton Academy

Responsive single-page academy website for JNBC Shuttlerz Badminton Academy.

## Live preview

https://shukritobi.github.io/jnbc-shuttlerz-badminton-academy/

## Included

- Coaching programme overview
- Coach profile
- Beginner and intermediate training journey
- Official Instagram embeds
- WhatsApp enquiry form
- Responsive mobile navigation and sticky WhatsApp CTA
- GitHub Pages deployment workflow

## Deployment

The site is deployed through `.github/workflows/pages.yml`. In the repository settings, set **Pages > Build and deployment > Source** to **GitHub Actions**.
